# Computational-physics-2

This repository contains the solutions, code, and reports for the homework assignments of the **Computational Physics 2** course. The numerical methods and simulations are mainly developed in **Python** y **Wolfram (Mathematica)**.

---

## 🛠️ Programming languages

* **Python:** For the implementation of numerical algorithms, data analysis, and simulations.
* Main libraries: `numpy`, `scipy`, `matplotlib`, `sympy`.

* **Wolfram Language / Mathematica:** For symbolic computation, advanced algebraic analysis, and verification of results.
* **LaTeX:** For rendering equations in the documentation and reports.

---
